# Local Mac updates

The user wants every completed Mac update installed over the daily application.
Use the destination in `.local-install-path`. Run the checks appropriate to the
change before building. `scripts/build.sh` installs a successfully signed build
automatically when that file exists. If Margin is running, quit it normally
through the app before installing; do not force termination. Verify the installed
version and signature. Keep reading data and Keychain credentials unchanged.

# Interface copy

Keep related explanations together and place their action button below the text.
Use short, plain wording in every supported language.
