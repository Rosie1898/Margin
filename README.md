# Margin

A local PDF reader for macOS and Windows. Keep your notes and AI conversations beside the passages they refer to.

一个面向 macOS 和 Windows 的本地 PDF 阅读器，把笔记和 AI 讨论留在原文旁边。

[Release notes / 发布说明](RELEASE_NOTES.md) · [GitHub Release](https://github.com/Rosie1898/Margin/releases/tag/v0.5.3)

The macOS build uses an ad-hoc signature and is not notarized. The Windows installer has no purchased code-signing certificate. Follow the platform guide for first-launch instructions.

Mac 版采用 ad-hoc 签名，尚未进行 Apple 公证；Windows 安装包没有购买的代码签名证书。首次打开方式见对应平台说明。

Source code lives in `mac/current/` and `win/`. Earlier Mac commits and release tags remain in the repository history.

两端源码分别位于 `mac/current/` 和 `win/`，原有 Mac 提交历史与发布标签继续保留。
